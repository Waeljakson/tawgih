# V1.0.83 — Campus + Stage Activity Analytics

This release upgrades the guidance statistics page so activity is no longer summarized only at the campus level.

## Hierarchy

- Bubble `School` is displayed as the **campus / complex (المجمع)**.
- Bubble `Department` is displayed as the **stage (المرحلة)**.
- Every campus is rendered as a group header with its overall totals.
- The activity rows underneath are grouped by Department within that campus.

## Metrics per stage

- Plan completion
- Programs
- Sessions
- Total recorded activity
- Unique beneficiary students

The existing year, term, campus and permission filters remain in force. No database or workflow changes are required.
