# V1.0.47

- Guardian mobile is linked directly to `Students -> Parent phone`, including exact casing aliases and on-demand Student hydration.
- Record name is fixed to the canonical record type and cannot be edited.
- Student Reports initializes safely before the report button is usable.
- Student Reports always includes every saved record associated with the selected student.
- If no records exist, the UI explicitly shows `لا يوجد سجلات للطالب ...`.
- Report filters were simplified to student selection because the requested report is all records.
- Removed the extra student summary row that changed layout after selecting a student.
- Linked grade/class/phone inputs keep a fixed compact height.
- Multiline text fields are collapsed to their title; clicking the title opens the multiline editor.
