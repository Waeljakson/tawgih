# V1.0.49

- Fixed searchable student selectors so linked student fields update on the `input` event immediately when a datalist result is selected.
- `guardian_phone` is now explicitly populated from the selected Student's `Parent phone` value.
- Repeater student rows use the same immediate binding path.
- Parent phone values stored as scientific-notation text (for example `9.66506E+11`) are expanded to a readable integer string.
- No additional Bubble workflow change is required; the current `students` bootstrap payload already includes `Parent phone`.
