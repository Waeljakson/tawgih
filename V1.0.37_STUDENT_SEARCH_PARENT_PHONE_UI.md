# V1.0.41

- Every single-student record now contains a read-only `رقم جوال ولي الأمر` field, auto-filled from `Students -> Parent phone`.
- Student repeaters also include an auto-filled guardian phone column.
- All student selectors in digital records are searchable by typing part of the student's name.
- Guardian-name textboxes are removed from record forms.
- Student Reports uses the current authorized student directory as the authoritative name list; archived records only add record counts/details.
- Student Reports student selector is searchable.
- User-facing technical references to the backend provider were removed from platform copy.
