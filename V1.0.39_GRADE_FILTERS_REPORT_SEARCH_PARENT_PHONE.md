# V1.0.39

- Restored `الصف` as a real compact readonly field in every direct-student record.
- Grade, class, and guardian phone are fixed-height and do not grow after student selection.
- Restored all Student Report filters.
- Added a custom live student-name search dropdown to Student Reports.
- Default report still includes all records for the selected student; filters narrow it when used.
- Shows `لا يوجد سجلات للطالب ...` when the selected student has no records at all.
- Removed legacy records subscription gating for the school platform.
- Added bootstrap support for `student_phones`.
- Direct phone list is only paired by index when its length exactly matches the scoped Students list, preventing wrong-phone assignment.
- Multiline editors always start collapsed and open only when their title is clicked.
