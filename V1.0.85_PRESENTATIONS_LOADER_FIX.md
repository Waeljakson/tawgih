# V1.0.85 — Presentations loader fix

- Fixed School Edition presentations page remaining permanently on the loading gate.
- Root cause: `app-v12.js` referenced `openCustomRequest`, `loadMyRequests`, `renderMyRequests`, `submitCustomRequest`, and `loadAccount` after those definitions were removed during the School Edition fork. The ReferenceError stopped `init()` before the loading gate was hidden.
- Restored School Edition-safe implementations.
- Custom presentation requests stay inside the school build/local storage; no Supabase is required.
- Removed the obsolete Supabase CDN script from the presentations page.
- Added cache busting to `presentations/app-v12.js`.
- Presentation content remains view-only inside the platform; no download/export function was added.
