# V1.0.79 — Report headings + session calendar alerts

- Centered all collective-guidance report column headings while preserving the white header text.
- Every `next_session_date` found in school digital records is surfaced as a Follow-up event in the Smart Calendar.
- `Guidance_Collective.next Date` and `Guidance_SubCollective.next Date` are also read from Bubble, so the calendar remains populated across devices.
- Calendar events automatically become reminders through the existing Smart Reminders engine.
- Record-save broadcasts refresh the reminder/calendar widgets immediately.
- No Bubble schema changes.
