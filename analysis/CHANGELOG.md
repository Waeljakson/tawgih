# تحديث V3 — شريط تنقل موحد احترافي

- استبدال القوائم العائمة بشريط منصات مؤسسي ثابت أعلى الصفحة.
- إبراز المنصة الحالية، والمنصات المتاحة، وغير المفعلة، والقادمة.
- عرض اسم الباقة الحالية وحالتها وتاريخ انتهائها بصورة واضحة.
- تحسين كامل للعرض على الهاتف والتابلت مع تمرير أفقي منظم.
- إضافة زر واضح للعودة إلى بوابة المنصات.

# سجل التغييرات

## V8 — الباقات المنفصلة والباقة الشاملة
- فصل صلاحيات منصة تحليل النتائج عن منصة السجلات الرقمية.
- إضافة باقة التحاليل: 10 ريالات شهريًا أو 50 ريالًا سنويًا.
- إضافة الباقة الشاملة: 50 ريالًا شهريًا أو 300 ريال سنويًا.
- توحيد طلبات التفعيل في لوحة المدير مع إظهار اسم الباقة والمنصة المصدر.
- تفعيل الطلب يمنح الباقة المحددة فقط؛ الباقة الشاملة وحدها تفتح جميع المنصات.
- عرض باقات كل مستخدم وتواريخ انتهائها في لوحة الإدارة.
- حماية قاعدة البيانات بسياسات RLS خاصة بكل منصة.
