# V1.0.49 — Direct student class list

Bubble bootstrap now provides:
- `students` = Current User's user data's Students
- `student_classes` = Current User's user data's Students:each item's Class's Titel

The frontend pairs both lists strictly by index before any filtering:
- students[0] -> student_classes[0]
- students[1] -> student_classes[1]

This removes the dependency on Student/Class Data API relation hydration for displaying the class.
