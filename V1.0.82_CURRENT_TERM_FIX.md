# V1.0.82 — Current Academic Term Fix

- Fixed the term resolver that incorrectly treated Bubble `Active` as `isCurrent`.
- `Active` now means enabled only.
- Current term priority: explicit current/default flag -> matching start/end dates -> semantic term order (الفصل الأول, الثاني, الثالث).
- Prevents الفصل الثاني from being selected merely because Bubble returned it first.
- No database schema or Workflow API changes.
