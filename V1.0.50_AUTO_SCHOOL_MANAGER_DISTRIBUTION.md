# V1.0.50 — Automatic school manager in distribution data

- The **School Manager** value in **Distribution Data** is filled automatically.
- Manager lookup is scoped to the current user's assigned School.
- Supports Bubble `Users Data -> Current Job -> job_titels -> Job Titel`.
- Supports employees assigned to multiple Schools / Departments.
- Prevents a `مدير المجمع` / `مدير المجمعات` record from being mistaken for `مدير المدرسة`.
- Existing direct School -> manager/principal relation remains the highest-priority source when available.
- No manual manager entry is required.
