# V1.0.49 — Chat counselor directory endpoint

Authoritative directory source:
GET /api/1.1/wf/guidance_counselors

The endpoint is already filtered in Bubble by:
Users Data -> Current Job = Job Titels:first item
where Job Titel = موجه طلابي

Frontend:
- Uses the endpoint directly for the counselor list.
- Displays Users Data -> Full Name.
- Merges matching directory metadata by Users Data ID.
- Group chat contains all returned counselors.
- Clicking a counselor opens the existing one-to-one chat flow.
- Legacy role inference is used only as a temporary network fallback.
