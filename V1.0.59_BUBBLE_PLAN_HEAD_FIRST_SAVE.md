# V1.0.59 — Bubble Plan Head-First Persistence

- Guidance_Plan is now the authoritative save.
- Guidance_Plan_Item sync is secondary and can no longer roll back/delete a verified plan head.
- If Bubble rejects optional Guidance_Plan fields with 400/422, the app retries a minimal head (Title, Notes, Active) then patches optional fields one by one.
- Plan listing falls back to privacy-scoped Guidance_Plan rows when the Guide relationship filter is unavailable.
- Bubble errors now distinguish 401/403/404/405/400/422/429/5xx/network/timeout cases.
- Full plan model remains in Guidance_Plan.Notes for lossless reopening and statistics.
