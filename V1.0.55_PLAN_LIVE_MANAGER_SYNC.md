# V1.0.55 — Plan live school-manager sync

- The plan page no longer reads `managerName` only once at startup.
- It listens to `mishkat:school-context-ready` and `mishkat:school-context-changed`.
- It explicitly invokes `resolveManagerDirect()` if the manager is not yet available.
- When the manager arrives, `#principalName` is populated immediately.
- If a plan is already generated/open, `state.currentPlan.form.principalName` and the rendered/print preview are updated automatically.
- The plan application script now uses the school build cache key so old `app-v13.js` cannot remain cached.
