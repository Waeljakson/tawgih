# V1.0.47 — Counselor chat directory

Chat behavior:
- User directory shows only active Users Data rows whose Current Job is `موجه طلابي`
  (with equivalent counselor labels supported for normalization).
- `مجموعة الموجهين الطلابيين` is always the first item and opens the group conversation.
- Clicking any counselor opens a private one-to-one conversation immediately.
- Search filters counselor names, schools, and stages.
- Current user is excluded from the private-contact list but included in the group count.
- Existing Guidance_Message persistence is reused; no new Bubble data type is introduced.
