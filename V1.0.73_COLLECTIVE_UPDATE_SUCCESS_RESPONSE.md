# V1.0.73 — Collective update success response

- Fixed `guidance_update_collective` false failure when Bubble returns HTTP 2xx with its standard `status: success` wrapper but no custom `success` key.
- Explicit custom `success: yes/true/1` remains supported.
- Real HTTP errors remain blocking and are not converted to success.
- After a confirmed update, the existing report-navigation flow remains active.
