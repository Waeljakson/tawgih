# V1.0.65 — Collective Guidance_Time relation fix

The collective guidance workflow parameter `duration` is a Bubble `Guidance_Time` Thing, not text/number. The frontend previously sent the form's numeric duration directly, causing Bubble `INVALID_DATA`.

This release loads `Guidance_Time` through the authenticated Bubble directory, resolves the selected duration by id/name/minutes, and sends the matching Bubble Thing reference. If no match exists, the optional parameter is omitted so the record still saves.
