# V1.0.71 — Collective Guidance Report UX

- After a successful save or update, the application switches immediately to the report view and refreshes Bubble-backed records.
- Opening an existing record changes the main button label to **حفظ التعديل**; new records show **حفظ السجل**.
- The collective guidance report was restyled with the Mishkat blue/teal visual identity.
- Long text cells wrap cleanly and are clamped on screen, with full values available in the cell title and full text in print.
- Action buttons use a sticky actions column for easier use on wide reports.
- Screen and print sizing were refined without changing Bubble schema or old records.
