# V1.0.60 — Guidance Plan Workflow API

## Endpoint
`POST /version-test/api/1.1/wf/guidance_save_plan`

## Authentication
Uses the existing signed-in Bubble user Bearer token. No admin token is stored in the frontend.

## Parameters sent
- `grade` → current school (`Grade` Thing)
- `school` → current complex (`School` Thing)
- `title` → automatic plan title
- `term` → selected `terms` Thing
- `academic_year` → selected/current `academic year` Thing
- `department` → current `Department` Thing
- `notes` → complete plan JSON
- `status` → `in_progress` / `completed`
- `active` → `yes`

`Guide` is intentionally resolved inside Bubble from `Current User -> Users Data`, as configured in the workflow.

## Bubble response
The frontend accepts the save only when `success` is true/yes. `message` is optional. `plan_id` is supported if added later but is not required for the initial save workflow.
