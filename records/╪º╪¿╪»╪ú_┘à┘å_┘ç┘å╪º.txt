منصة السجلات الرقمية للموجه الطلابي — V2

1) ارفع جميع محتويات هذا المجلد إلى مستودع GitHub الخاص بمنصة السجلات.
2) استبدل النسخة السابقة بالكامل.
3) انتظر اكتمال GitHub Pages ثم استخدم Ctrl + F5.

الباقات:
- السجلات: 10 ريالات شهريًا أو 50 ريالًا سنويًا.
- الشاملة: 50 ريالًا شهريًا أو 300 ريال سنويًا.

قاعدة البيانات الحالية محدثة بالفعل. مدير النظام يرى طلبات جميع المنصات.
