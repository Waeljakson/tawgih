# منصة السجلات الرقمية للموجه الطلابي

منصة ويب عربية تعمل على GitHub Pages وترتبط بقاعدة Supabase الحالية للمستخدم. صُممت لتحويل سجلات التوجيه الطلابي الورقية إلى نماذج إلكترونية منظمة قابلة للحفظ والبحث والطباعة.

## السجلات المتاحة

1. الإرشاد الجمعي
2. إرشاد فردي لحالة ضعف دراسي
3. إرشاد فردي لمشكلة تعليمية
4. إرشاد فردي لمشكلة سلوكية
5. إرشاد فردي لمتكرري التأخر
6. إرشاد فردي لمتكرري الغياب
7. التواصل مع ولي الأمر
8. الزيارة التوجيهية
9. دراسة الحالة — سري للغاية
10. دعوة ولي أمر
11. زيارة الملاحظة
12. مقابلة طالب مستجد
13. مقابلة فردية
14. سجل المواقف اليومية
15. حصر تحويل حالات التأخر
16. حصر تحويل حالات الغياب

## الهوية

لا تحتوي المنصة على اسم مدرسة أو شعار ثابت. يضيف المستخدم اسم المدرسة وشعارها من الإعدادات، ويظهران في رأس السجلات وفي الطباعة.

## الاشتراك

- الحساب التجريبي: تعبئة النماذج ومعاينتها فقط.
- باقة السجلات شهريًا: 10 ريالات لمدة شهر.
- باقة السجلات سنويًا: 50 ريالًا لمدة 12 شهرًا.
- الباقة الشاملة شهريًا: 50 ريالًا لجميع المنصات.
- الباقة الشاملة سنويًا: 300 ريال لجميع المنصات.
- طلب التفعيل يتم بعد التواصل عبر واتساب على الرقم 00966582712620.

## المزايا

- تسجيل الدخول وإنشاء الحسابات بواسطة Supabase Auth.
- استخدام حساب دخول موحد مع صلاحيات منفصلة لكل منصة؛ اشتراك السجلات لا يفتح منصة التحاليل.
- حفظ السجلات في `public.guidance_digital_records` مع حماية RLS.
- أرشيف مع البحث والتصفية والتعديل والحذف.
- طباعة A4 أو حفظ PDF للمشتركين.
- شاشة حماية وعلامة نسخة تجريبية للحساب غير المشترك، وتُزال تلقائيًا للمشترك والمدير.
- محادثة دعم فني داخل الصفحة.
- لوحة مدير لتفعيل الاشتراكات وتعيين مديرين ومراجعة الدعم.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا.
2. ارفع محتويات هذا المجلد إلى الفرع `main`.
3. افتح Settings > Pages واختر GitHub Actions.
4. انتظر اكتمال Workflow باسم Deploy GitHub Pages.

## ملفات المشروع

- `index.html` واجهة المنصة.
- `styles.css` التصميم والطباعة.
- `app.js` النماذج والقاعدة والاشتراك والدعم.
- `.github/workflows/pages.yml` النشر التلقائي.

## نظام الباقات المنفصلة — V2
- باقة السجلات الرقمية: 10 ريالات شهريًا أو 50 ريالًا سنويًا، وتفتح الحفظ والطباعة والأرشيف في منصة السجلات فقط.
- باقة تحليل النتائج منفصلة، ولا يمنح الاشتراك فيها مزايا السجلات الرقمية.
- الباقة الشاملة: 50 ريالًا شهريًا أو 300 ريال سنويًا، وتفتح جميع المنصات الحالية والمستقبلية.
- يمكن استخدام حساب الدخول نفسه، لكن كل منصة تتحقق من استحقاقها المستقل. الحساب المشترك في باقة أخرى يبقى تجريبيًا هنا ما لم تكن الباقة الشاملة مفعلة.
- تظهر جميع طلبات التفعيل لمدير النظام في لوحة الإدارة داخل أي منصة، ويظهر مع كل طلب اسم الباقة والمنصة المصدر.


> هذه النسخة مدمجة داخل البوابة الموحدة. استخدم الرابط `../index.html` للعودة إلى لوحة المنصات.
