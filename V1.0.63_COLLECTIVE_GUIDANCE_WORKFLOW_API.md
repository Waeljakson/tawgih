# V1.0.63 — Collective Guidance Workflow API

The digital-records module now routes `group_guidance` through authenticated Bubble Backend Workflows:

- `guidance_save_collective` for first save.
- `guidance_update_collective` for an existing local archive record.
- `guidance_delete_collective` for deletion.

## Payload mapping

- `academic_year` <- current/selected academic year Bubble reference
- `collective_date` <- record date
- `collective_name` <- session title
- `collective_target` <- selected student names
- `dep` <- Department reference
- `duration` <- form duration when present
- `evaluation` <- evaluation
- `grade` <- Grades reference (school)
- `next_date` <- next session date when present
- `orders` <- student tasks
- `procedures` <- procedures
- `process` <- session flow
- `school` <- School reference (complex)
- `students` <- selected Students references
- `term` <- terms reference
- `tools` <- tools

Updates additionally send `original_collective_date` and `original_collective_name`, matching the Bubble search-based update workflow configured by the user. Deletes send the identity/context fields configured in `guidance_delete_collective`.

No manual Bubble IDs are exposed in the UI.
