# V1.0.68 — Collective Guidance complete save/report

- Corrected `Collective target` to store session objectives instead of participant names.
- Duration now resolves against `Guidance_Time` in both supported shapes: a Bubble data type (unique reference) or an option set (Display value); entered duration is never silently dropped.
- Remote report hydrates `Guidance_Time` labels and reads all persisted `Guidance_Collective` fields.
- Report table now shows title, objectives, participants, stage, campus, duration, procedures, tools, process, student orders, next date and evaluation.
- Bubble remote values take precedence over stale local mirror values while local-only signatures/counselor display remain preserved.
- After successful save, the app awaits report refresh and opens the record report immediately.
- No Bubble schema/database change required.
