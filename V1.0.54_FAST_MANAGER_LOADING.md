# V1.0.54 — Fast manager loading

The automatic school-manager value is now prefetched instead of being resolved only after the distribution dialog is opened.

Performance changes:
- immediate lookup when school scope exists; no 900 ms timer;
- parallel school-scoped Bubble queries;
- first successful scoped response can populate the UI without waiting for slower sibling queries;
- session + six-hour local cache keyed by the exact assigned school scope;
- cached value is shown immediately and verified once in the background;
- fewer bootstrap polling rounds.

No subscription/package logic was reintroduced. The school edition remains free.
