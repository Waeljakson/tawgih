# V1.0.71 — Guidance_Time dropdown

- Collective guidance `duration` is no longer a numeric/text input.
- It is rendered as a dropdown sourced from Bubble Option Set `Guidance_Time`.
- The selected option Display/name is sent directly to `guidance_save_collective` and `guidance_update_collective`.
- No database schema changes. Existing records remain untouched.
- The bootstrap payload may expose the list under `guidanceTimes`, `guidance_times`, `guidanceTime`, `Guidance_Time`, or `Guidance Time`.
